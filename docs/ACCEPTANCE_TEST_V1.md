**تحقّق SQL:**
```sql
-- (أ) المُنتِج يعمل: يجب أن تظهر صفوف بمفاتيح preview:/rev:
select status, left(coalesce(idempotency_key,''),46) as idem, subject, last_error
  from public.email_deliveries
 where created_at > now() - interval '1 hour'
 order by created_at desc limit 20;

-- (ب) لا تكرار إطلاقًا:
select idempotency_key, count(*) from public.email_deliveries
 where idempotency_key is not null group by 1 having count(*) > 1;
-- المتوقَّع: صفر صفوف
```

> **مهم:** بقاء الصفوف `status='pending'` مع `last_error='relay_handler_missing'` هو
> **السلوك الصحيح المصمَّم** ما دام معالج Google Apps Script مؤجَّلًا بطلبك. الرسائل
> محفوظة ولا تُستهلك محاولاتها، وتُرسَل تلقائيًّا خلال ~30 دقيقة من تركيب المعالج.
> ظهور الصفوف = **الإشعارات الداخلية جاهزة**. عدم ظهورها = مشكلة حقيقية أبلغني بها.
