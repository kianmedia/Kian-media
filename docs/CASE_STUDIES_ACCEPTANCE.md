## د) بوّابات الإذن والسرّية (الجوهر)

| # | الإعداد | المتوقّع عند محاولة النشر |
|---|---|---|
| D1 | الرؤية `named` بلا إذن بالاسم | مانع `named_without_permission` — **لا نشر** |
| D2 | الرؤية `named` والإذن يشترط التجهيل | مانع `anonymization_required` |

| D7 | إذن حالته `granted` لكن `permission_expires_at` مضى | يُعامَل كغياب إذن — منتهٍ ليس ساريًا |
| D8 | اسم موظّف بلا موافقة | يُنشر **بدونه**، وتحذير يقول ذلك صراحةً. غيابه سلوك مقصود لا عطل |
| D9 | الرؤية `anonymized` بلا تسمية | القاعدة ترفض الحفظ من الأساس |
| D10 | نصّ نتائج يذكر «ريال» أو «ميزانية» | تحذير `possible_financial_figure` — لا يمنع، يطلب عينًا بشرية |

## ح) الرفض النهائيّ (فشل واحد = عدم قبول)

- ظهور اسم عميل أو شعاره أو رقمه أو شهادته بلا إذن مسجَّل.
- ظهور اسم موظّف بلا موافقة موثَّقة.
- ظهور تكلفة أو هامش في أيّ مخرَج عامّ.
- ظهور رابط تخزين خاصّ أو رابط معاينة داخليّ في صفحة عامّة.
- نشر تمّ من غير المالك.
- «لا تملك صلاحية» تُعرَض بوصفها ترحيلة ناقصة، أو العكس.
- انهيار أو صفر مضلّل في أيّ صفحة والـSQL غير مطبَّق.
