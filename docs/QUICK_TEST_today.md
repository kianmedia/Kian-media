## ١) تعليق المشروع بسبب إلزاميّ
**المسار:** `فتح المشروع → دورة حياة المشروع → إجراءات المشروع → تعليق المشروع`

1. تحقّق أنّ صفّ **«إجراءات المشروع:»** ظاهر أسفل شريط المراحل.
2. اضغط **«تعليق المشروع»** ← تفتح نافذة.
3. **اترك السبب فارغًا** ← لاحظ أنّ زرّ «تأكيد التعليق» **معطّل** وتحته «اكتب السبب لتفعيل التأكيد».
4. اكتب سببًا ← اضغط **«تأكيد التعليق»**.

| المتوقَّع | ✅/❌ |
|---|---|
| النافذة تشرح الأثر: تتوقّف المراحل، ولا تُعدَّل المواعيد، ولا تُحذف بيانات | ☐ |
| الزرّ معطّل بلا سبب | ☐ |
| بعد التأكيد: «عُلّق المشروع.» وتظهر شارة **«معلّق»** برتقالية | ☐ |

## ٢) تعطيل شريط المراحل أثناء التعليق
**نفس الشاشة، مباشرة بعد الخطوة ١.**

| المتوقَّع | ✅/❌ |
|---|---|
| كل أزرار المراحل **باهتة وغير قابلة للنقر** | ☐ |
| عند المرور فوق أيّ مرحلة يظهر: «المراحل موقوفة — استأنف المشروع أو أعد فتحه أولًا.» | ☐ |
| سطر تحت الأزرار: «انتقال المراحل موقوف في هذه الحالة الإدارية.» | ☐ |

---

## ٣) الاستئناف والعودة للمرحلة السابقة
**قبل التعليق سجّل المرحلة الحالية** (مثلًا «قيد الإنتاج»).

1. اضغط **«استئناف المشروع»** ← اكتب ملاحظة ← أكّد.

| المتوقَّع | ✅/❌ |
|---|---|
| المشروع يعود إلى **المرحلة نفسها** التي كانت قبل التعليق (لا «التخطيط» ولا أي مرحلة ثابتة) | ☐ |
| شارة «معلّق» تختفي · أزرار المراحل تعمل من جديد | ☐ |

**تحقّق:**
```sql
select from_stage, to_stage, note, created_at
  from public.project_status_history
 where project_id = '<المشروع>' order by created_at desc limit 4;
-- المتوقَّع: سطر (X → on_hold) ثم سطر (on_hold → X) بنفس X، والسبب مسجَّل في note
```

## ٤) الإلغاء وظهور «ملغي»
> استخدم **مشروع تجربة** — الإلغاء لا يُحذف لكنّه يوقف التشغيل.

1. `إجراءات المشروع → إلغاء المشروع` ← اكتب سببًا ← أكّد.

| المتوقَّع | ✅/❌ |
|---|---|
| النافذة تقول صراحة إنّ الإلغاء **لا يحذف** المخرجات والملفات والتعليقات والسجلّ | ☐ |
| تظهر شارة **«ملغى»** حمراء · شريط المراحل معطّل | ☐ |
| يظهر سطر: «المشروع ملغى — لا إجراءات تشغيلية.» | ☐ |
| المخرجات والتعليقات ما زالت ظاهرة في تبويباتها | ☐ |

## ٥) طلب تغيير: فتحه وتنفيذ انتقالاته
**المسار:** `فتح المشروع → الحوكمة → طلبات التغيير`

1. **+ إضافة** ← عنوان + وصف ← **اترك «أيام إضافية» فارغًا** ← حفظ.
2. **انقر على السطر** في القائمة ← تفتح نافذة التحرير.
3. اضغط الأزرار بالترتيب: **«مُرسل للمراجعة الداخلية»** ← **«تحليل الأثر»** ← **«بانتظار اعتماد العميل»** (يطلب تأكيدًا) ← **«معتمد»**.
4. اضغط **«تطبيق على المشروع»** ← ثمّ افتح الطلب واضغط **«تطبيق»** **مرّة ثانية**.

| المتوقَّع | ✅/❌ |
|---|---|
| الحفظ ينجح رغم ترك «أيام إضافية» فارغًا | ☐ |
| السطر **قابل للنقر** وتفتح نافذة كاملة | ☐ |
| تظهر فقط الانتقالات المسموحة في كل حالة (لا قفز) | ☐ |
| «بانتظار اعتماد العميل» يطلب تأكيدًا صريحًا | ☐ |
| جرّب **«مرفوض»** بسبب فارغ ⇒ يُرفض: «سبب الرفض إلزامي» | ☐ |
| الضغط الثاني على «تطبيق» ⇒ **`already_applied`** ولا يتضاعف الأثر | ☐ |
| كل القوائم بالعربية (مسودة/تحليل الأثر/معتمد…) لا `draft`/`approved` | ☐ |

**تحقّق:**
```sql
select status, applied_at, schedule_impact_days
  from public.project_change_requests
 where project_id = '<المشروع>' order by created_at desc limit 3;
-- المتوقَّع: applied_at مضبوط مرّة واحدة فقط
```

## ٦) حل مشكلة وإغلاقها
**المسار:** `الحوكمة → المشكلات`

1. **+ إضافة** ← عنوان ← حفظ. 2. **انقر السطر** ← غيّر الحالة إلى **«محلولة»** ← **اترك ملخّص الحل فارغًا** ← حفظ.
3. اكتب ملخّص الحل ← حفظ.

| المتوقَّع | ✅/❌ |
|---|---|
| قائمة الحالة بالعربية: مفتوحة/قيد الفحص/قيد المعالجة/محلولة/مغلقة… | ☐ |
| عند اختيار «محلولة» يظهر حقل **ملخّص الحل** بلون تنبيه | ☐ |
| الحفظ بلا ملخّص ⇒ «سبب الإغلاق/الحل إلزامي» | ☐ |
| بعد كتابته: يُحفظ وتتغيّر الحالة في السجل | ☐ |
| عدّاد «المشكلات الحرجة» في أعلى الحوكمة يتحدّث | ☐ |

---

## ٧) اعتماد قرار
**المسار:** `الحوكمة → القرارات`

1. **+ إضافة** ← عنوان ← حفظ. 2. **انقر السطر** ← املأ **القرار** و**المبرّر** و**البدائل** و**الأثر** ← غيّر الحالة إلى **«معتمد»** ← حفظ.

| المتوقَّع | ✅/❌ |
|---|---|
| الحقول الأربعة موجودة وتُحفظ | ☐ |
| قائمة الحالة بالعربية: مقترح/معتمد/مُستبدَل/معكوس/مؤرشف | ☐ |
| بعد الحفظ تظهر «معتمد» في السجل | ☐ |

---

## في حال الفشل
أرسل لي: **رقم الاختبار** + **نصّ رسالة الخطأ حرفيًّا** + لقطة إن أمكن.
رسائل مثل `bad_stage` أو `violates check constraint` أو `not authorized` تحدّد السبب فورًا.
