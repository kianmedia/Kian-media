# PRODUCTION_BACKUP_RESTORE_RUNBOOK

> 🔴 **الحالة: `RESTORE DRILL REQUIRED — NOT EXECUTED`.**
> ⛔ **لم تُؤخذ نسخة، ولم يُجرَّب استرجاع، ولا وصول للإنتاج.** هذا إجراء يُنفَّذ بيد خالد.

---

## ١. لماذا قبل أيّ SQL

الحزم التسع **إضافية** ولا تحذف بيانات — ⚠️ **لكنّ التراجع ليس مجّانيًّا**:
حزمة تُنشئ فهارس على جداول كبيرة قد تطيل القفل، وحزمة تعدّل قيدًا قد تكشف صفوفًا
مخالفة كانت مقبولة.

🔴 **والقاعدة الصلبة: نسخةٌ لم تُختبر استعادتها ليست نسخة.** «النسخ الاحتياطي
مفعَّل» ادّعاءٌ حتّى يُثبَت باسترجاع فعليّ.

---

## ٢. قبل النسخ — تحقّق من التوافر

1. لوحة Supabase ← Database ← Backups: هل النسخ اليوميّة **مفعَّلة**؟
2. ما **مدّة الاحتفاظ** فعليًّا؟ (تختلف بالخطّة)
3. هل **PITR** متاح؟
4. ⚠️ سجّل **آخر نسخة ناجحة بتاريخها** — ⛔ ولا تفترض أنّها الليلة الماضية.

⛔ **شرط توقّف:** لو لم تكن النسخ مفعَّلة أو لم تُعرف مدّة الاحتفاظ ⇒ **لا SQL**.

---

## ٣. النسخة المنطقية (مستقلّة عن المزوّد)

```bash
pg_dump --format=custom --no-owner --no-privileges \
  --file=kian_prod_$(date +%Y%m%d).dump "$DATABASE_URL"
```

⛔ **ولا تكتب `DATABASE_URL` في ملفّ ولا في تاريخ الصدفة** — مرّرها من مدير أسرار.
⚠️ ونسخة `pg_dump` **لا تشمل**: مستخدمي `auth` كاملين · كائنات التخزين ·
الأسرار · إعدادات المشروع. فهي **مكمِّلة** لنسخة المزوّد لا بديلة عنها.

| ما يجب الانتباه له | لماذا |
|---|---|
| `auth.users` | مملوك لـSupabase؛ الاسترجاع الجزئيّ يكسر الجلسات |
| كائنات التخزين | الملفّات **ليست** في القاعدة — البيانات الوصفية فقط |
| الأسرار ومفاتيح الخدمة | ⛔ لا تُنسخ إلى مكان غير مشفَّر |
| الامتدادات | `pgcrypto` وغيرها يجب أن توجد في الهدف |

---

## ٤. التحقّق من النسخة

1. حجم الملفّ **> 0** ومعقول مقارنةً بالسابق.
2. `pg_restore --list` يقرأ الفهرس بلا خطأ.
3. سجّل **البصمة** (sha256) والحجم والتاريخ.
4. ⛔ ولا يُعدّ «انتهى الأمر بلا خطأ» تحقّقًا.

---

## ٥. 🔴 تمرين الاسترجاع — والهدف **ليس الإنتاج**

⛔ **ولا يكون الهدف `kian-media-preview`** — تلك بيئة عاملة، والاسترجاع فوقها
يدمّر بياناتها. الهدف **مشروع/قاعدة مؤقّتة تُنشأ للتمرين وتُحذف بعده**.

**الخطوات:**
1. أنشئ هدفًا نظيفًا معزولًا.
2. `pg_restore` النسخة إليه.
3. قارن مع الإنتاج **قراءةً فقط**:

| المقارنة | الحكم |
|---|---|
| عدد صفوف كل جدول | فرق > 0 خارج نافذة النسخ ⇒ 🔴 تحقيق |
| عدد الجداول والأعمدة | أيّ فرق ⇒ 🔴 توقّف |
| عدد الدوالّ + `prosecdef` + `proconfig` | فرق ⇒ 🔴 توقّف (تعريف مختلف) |
| عدد المُشغِّلات | فرق ⇒ 🔴 توقّف |
| عدد سياسات RLS **لكل جدول** | فرق ⇒ 🔴 **الأخطر**: استرجاع بلا سياسات = بيانات مكشوفة |
| البيانات الوصفية للتخزين | فرق ⇒ سجّل (الملفّات نفسها خارج النسخة) |

4. ⛔ **احذف الهدف المؤقّت** بعد التمرين.

## ٦. دليل النجاح المطلوب

⛔ **لا يُقبل «تمّ» بلا:**
- تاريخ النسخة وحجمها وبصمتها.
- مخرَج `pg_restore --list` (أوّل وآخر سطر).
- جدول المقارنة أعلاه **مملوءًا بأرقام حقيقية**.
- اسم الهدف المؤقّت **وإثبات حذفه**.
- اسم من نفّذ ومن راجع.

- الهدف الوحيد المتاح بيئة عاملة.
- ⛔ أو أيّ إغراء بتشغيل التمرين **على الإنتاج**.
