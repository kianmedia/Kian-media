## ٢. تفصيل أعلام Wave 3

### `NEXT_PUBLIC_SHOW_OPS_SUN_WEATHER`

| | |
|---|---|
| **Default** | `OFF` (أيّ قيمة غير `"true"` بالضبط) |
| **الميزة** | الساعة الذهبية · الطقس · تحذير الدرون الإرشاديّ · التاريخ البديل |
| **Schema** | 🔴 `docs/wave3_production_ops_RUNME.sql` — **لم يُطبَّق** |
| **شروط التفعيل** | ١) تطبيق الحزمة · ٢) POSTCHECK كلّه ✅ · ٣) موقع واحد على الأقل بإحداثيات في `ops_locations` |
| **Rollback** | أعد العلم إلى فارغ ⇒ ورقة النداء تعود **حرفيًّا** كما كانت، والمسار يُرجع 404. لا حاجة لتراجع SQL |

**سلوك OFF (مُختبَر — E-11):** قسم الطقس القديم يظهر بنصّه الأصلي «لا إدخال
طقس.»، ولا يُستورَد شيء من طبقة الإثراء إلى المخرجات، و`/api/portal/ops/weather`
يُرجع **404 لا 403** — فلا يُقرّ بوجوده أصلًا.

⚠️ **تفعيله قبل تطبيق SQL:** الساعة الذهبية تعمل (حساب محلّيّ بحت)، والطقس يظهر
من الأعمدة القديمة، وزرّ التحديث يُرجع «يحتاج ترحيلة قاعدة لم تُطبَّق بعد».
لا انهيار — لكنّه وضع نصف عامل، فالترتيب الصحيح: SQL أوّلًا.

## ٣. تفصيل أعلام Waves 1–2

### `NEXT_PUBLIC_SHOW_TRUST_PAGE`
**Default OFF.** `/trust` و`/en/trust` ⇒ 404 · خارج sitemap · بلا canonical أو
hreflang · ولا نصّ يتسرّب إلى HTML عامّ.
**شروط التفعيل:** مراجعة خالد لنصوص الصفحة (**PENDING KHALED REVIEW**).
🔴 **ملاحظة:** السجل التجاري والرقم الضريبي لهما **بوّابة مستقلّة**
(`content/registration.ts` → `REGISTRATION_VERIFIED`). رفع علم الصفحة **لا**
يُظهرهما — يحتاجان **PENDING OFFICIAL DOCUMENT VERIFICATION**.

### `NEXT_PUBLIC_SHOW_CLIENT_LOGOS`
**Default OFF.** الشريط مبنيّ وغير مركَّب أصلًا.
**شرط التفعيل:** **PENDING LOGO USAGE RIGHTS** — حقوق استخدام ٦٢ شعارًا.

### `NEXT_PUBLIC_SHOW_SEO_PAGES`

## ٤. القاعدة العامّة عند التفعيل

1. طبّق SQL الحزمة (إن وُجدت) وشغّل POSTCHECK كاملًا.
2. ارفع العلم في Vercel — **متغيّر `NEXT_PUBLIC_*` يُدمَج وقت البناء**، فيلزم
   إعادة نشر. تغييره في اللوحة وحدها لا يفعل شيئًا.
3. تحقّق على Production بنفسك — لا شيء في هذا المستودع يُثبت سلوك Production.
4. عند أيّ شكّ: أعد العلم فارغًا وأعد النشر. هذا هو التراجع الأسرع دائمًا،
   وهو **لا يحتاج تراجع SQL** في كلّ أعلام هذه الموجات.
