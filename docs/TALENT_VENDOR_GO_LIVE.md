# دليل التشغيل — شبكة المواهب والمستقلّين والمورّدين

الحزمة: `docs/talent_vendor_network_{PREFLIGHT,RUNME,POSTCHECK,ROLLBACK}.sql`

---

## ٠) قبل أيّ شيء — قرار إعادة الاستخدام

| المفهوم | القرار | لماذا |
|---|---|---|
| المورّد الشرائيّ | **أُعيد استخدام `custody_vendors`** + عمود واحد `tvn_profile_id` | جدول مورّدين ثانٍ يعني رقمين لنفس المورّد، ولا أحد يعرف أيّهما الحقيقيّ |
| الأصول | **أُعيد استخدام `custody_inventory_assets`** كمالك محتمل لوثيقة | لم يُنشأ `asset_*` ولا نسخة من أصل واحد |
| سطح الفرص | **لم يُمسّ** `opportunity_requests` | لا مُشغِّل · لا استيراد تلقائيّ · **لا بريد** — ثغرة المرحّل المجهول تبقى مغلقة |
| الإشعارات | **أُعيد استخدام مركز الاتصالات** | لا طابور بريد جديد |
| الصلاحيات | **أُعيد استخدام** `permissions` + `emp_has_permission` | لا نموذج صلاحيات مواز |
| ملفّات الشبكة | **أُنشئت `tvn_*`** | لا شيء في المستودع يحمل مهنة/مهارة/لغة/تغطية/معدّات/توافر/وثائق/تقييم لشخص خارجيّ |

## ١) ترتيب التشغيل

```
١) docs/talent_vendor_network_PREFLIGHT.sql   ← اقرأ عمود verdict كاملًا
٢) docs/talent_vendor_network_RUNME.sql       ← معاملة واحدة، تفشل كاملة أو تنجح كاملة
٣) docs/talent_vendor_network_POSTCHECK.sql   ← لا سطر FAIL واحد
```

**BLOCKER في PREFLIGHT ⇒ لا تُشغّل RUNME.** الاعتماديات الصلبة أربع فقط:
`auth.users` · `is_staff()` · `is_owner()` · `is_admin()` — والأخيرة الثلاث
يجب أن تعيد `boolean`. غيابها لا يُنتج ميزة ناقصة بل يُسقط الترحيلة عند أوّل
`CREATE FUNCTION`، وأسوأ منه أن تعيد شيئًا غير `boolean` فتصير كلّ سياسة
فوقها «غير محدَّد» — وهو ليس منعًا.

`RUNME` يبدأ بـ`PREFLIGHT` صلب داخليّ يرفع `TALENT PREFLIGHT FAILED` قبل كتابة
حرف واحد، فحتّى من لصق الملفّ مباشرةً لا يحصل على ترحيلة نصفية.

## ٢) الاعتماديات الاختيارية — ما الذي يغيب إن غابت

| الغائب | الأثر الدقيق |
|---|---|
| `custody_vendors` | لا جسر مورّد. ⚠️ **ولا يُنشئ RUNME بديلًا** — `tvn_vendor_link` تُرجع `vendor_table_absent` بصراحة |
| `custody_inventory_assets` | لا وثائق مملوكة لأصل (مفتاح أجنبيّ فقط يُتخطّى) |
| `opportunity_requests` | `tvn_promote_opportunity` ترفع `feature unavailable` بدل اختراع بيانات |
| `comms_event_catalog` | الأحداث تُسجَّل في `tvn_event_log` محلّيًّا فقط |
| `permissions` / `emp_has_permission` | ★ لا يمرّ أحد غير المالك ★ — منع لا منح، لكنّه يعني وحدة بلا مستخدمين |

`tvn_access()` يُبلّغ الواجهة بكلّ ذلك، فتعرض «الميزة بانتظار تفعيل قاعدة
البيانات» بدل الانهيار أو الصمت.

## ٣) بعد التشغيل — خطوات المالك اليدوية

1. **امنح المفاتيح.** لا أحد غير المالك يملك شيئًا افتراضيًّا:
   `talent.view` · `talent.manage_profiles` · `talent.view_rates` ·
   `talent.view_bank` · `talent.verify_compliance` · `talent.assign_external` ·
   `talent.review_performance` · `talent.approve_cost`.
   ★ لا تمنح `view_rates` و`view_bank` للمهن التشغيلية ★
2. **اضبط الحدّ المالي:**
   `update public.tvn_settings set cost_approval_threshold = <القيمة>;`
3. **راجع الوثائق الإلزامية** في `tvn_document_types.is_required` و`applies_to`
   قبل إدخال أوّل مورّد — تغييرها لاحقًا يجعل ملفّات قائمة «ناقصة» فجأةً.
4. **اربط المورّدين القائمين** عبر `tvn_vendor_link` بدل إعادة إدخالهم.
5. **الأحداث تبقى صامتة.** لا تُفعّل قناة إرسال لها في هذه المرحلة.

---

## ٤) الإشعارات — ما يحدث فعلًا

- تُسجَّل ١٧ حدثًا في الكتالوج: ٧ بادئتها `talent.` تملكها هذه الحزمة، و١٠
  بادئتها `asset.` تملكها حزمة الأصول وتُعرَّف هنا بـ`on conflict do nothing`
  كي تلتقي الحزمتان على نفس المفاتيح أيًّا كان ترتيب التشغيل.
- **قناة `portal` وحدها.** لا `email` ولا `whatsapp` ولا `sms` في مصفوفة
  القنوات. `POSTCHECK` يفشل إن ظهرت أيّ منها.
- **هذا الملفّ لا يلمس `comms_channels` إطلاقًا** ولا يمرّر `dry_run` في أيّ
  موضع؛ قرار التفعيل يبقى للمالك داخل المركز.
- كلّ إدراج له مفتاح تفرُّد في `tvn_event_log`، فإعادة تشغيل المسح لا تُكرّر
  حدثًا.

⛔ **لا شيء يُرسَل.** الإدراج ليس إرسالًا، و«مُدرَج» ليس دليل تسليم.

## ٥) التحقّق اليدويّ (١٠ دقائق)

1. أنشئ ملفّ `freelancer` ثمّ اجعله `active`.
2. **جرّب إسناده الآن** ومهمّة تتطلّب درون → يجب أن يُرفَض بـ`drone_permit_missing`.
3. ارفع `drone_permit` بمستخدم أ، ثمّ حاول توثيقه **بالمستخدم نفسه** → يُرفَض.
4. وثّقه بمستخدم ب يملك `verify_compliance` → الإسناد يمرّ الآن.
5. أنشئ إسنادًا مؤكَّدًا، ثمّ حاول إسنادًا آخر متداخلًا زمنيًّا → `schedule_conflict`.
6. سجّل دخول موظّف بلا `talent.view_rates` وافتح الملفّ → **«غير مصرّح لك
   بعرض الأجر»**، لا صفر ولا شرطة.
7. أنهِ المهمّة، اكتب تقييمًا، أقفله، ثمّ حاول تعديله → يُرفَض؛ ثمّ صحّحه بسبب
   مكتوب → يُلحَق ولا يُمسّ الأصل.
8. اقرأ `tvn_rating` لملفّ بتقييم واحد → `insufficient_sample`، لا رقم.
