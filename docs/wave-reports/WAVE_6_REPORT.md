## ٢. V2-6.1-A — الصفحة **ليست عامّة**، وهذا هو العقد

`QR_SECURITY_CONTRACT.md` §٥ صريح:

> «لا بحث مجهول الهوية في V1. الاختيار متعمّد: بحث عامّ ولو بحمولة فقيرة يعطي
> مجهولًا القدرة على **تأكيد أنّ رمزًا ما حقيقيّ**.»

والـBrief يقول «تخضع لـ`QR_SECURITY_CONTRACT.md`» — فالعقد حاكم.

| | السلوك |
|---|---|
| زائر بلا جلسة | **رسالة محايدة واحدة** لا تنفي ولا تؤكّد وجود الرمز |
| موظّف بلا صلاحية أصول | «لا تملك صلاحية» |
| موظّف | حمولة متدرّجة يقرّرها **الخادم** |

والصفحة تمرّ عبر `custody_inv_qr_scan` **وحدها** — `..._public_payload` مسحوبة
من الجميع، فتجاوزها يعني تحديد معدّل وتدقيقًا قابلَين للتجاوز. والحقول **قائمة
بيضاء صريحة**، فتغيّر لاحق في الخادم لا يُسرّب سعرًا أو موظّفًا أو مسار تخزين
إلى ورقة معلّقة على معدّة.

## ٣. 🔴 انحراف موثَّق: V2-6.6-A ليس جدولًا جديدًا

الـBrief يطلب `sops` 🆕. والفحص أثبت أنّ قاعدة المعرفة **قائمة بالكامل**:

| ما يلزم إجراءً | في `ai_knowledge_sources` |
|---|---|
| نوع «إجراء تشغيليّ» | ✅ `source_type` يقبل `'operations_procedure'` **أصلًا** |
| مسوّدة/مراجعة/اعتماد/رفض/انتهاء/أرشفة | ✅ `status` بالقيم الستّ |
| صلاحيات | ✅ `allowed_roles text[]` + `sensitivity` |
| إصدارات | ✅ `ai_source_revisions` |
| مسار اعتماد | ✅ `submitted_by`/`approved_by`/`rejected_reason` |
| مرفقات | ✅ `storage_bucket`/`storage_path` |

⇒ `sops` كان سيصير **قاعدة معرفة ثانية**. الجديد الوحيد خطواته المرتَّبة
(`sop_items`)، وهي لا توجد في أيّ جدول.

## ٤. ما يرفضه هذا البناء

| القاعدة | كيف فُرضت |
|---|---|
| لا سجلّ حوادث رابع | HSE **عرض** يقرأ الثلاثة ولا يكتب (N-2 + فحص طفريّ) |
| لا نظام أصول/عهدة/صيانة ثانٍ | (N-1) يمنع ١٤ اسمًا، ويمنع `alter`/`delete` على ستّة أنظمة قائمة |
| الأرشفة ليست حذفًا | `link_status` يشمل **`missing`** — الفقد يظهر ولا يُخفى |
| صحّة الوسيط تُدخَل لا تُستنتَج | `health_status` افتراضه `unknown` |
| PDPL — أقلّ بيانات | لا هويّة ولا عنوان ولا ميلاد (فحص طفريّ يمنع إضافتها) |
| لا رابط تخزين مخزَّن | `bucket`+`path` + قيد يرفض `^https?://` في حقل المسار |
| حقّ السحب | `withdrawn_at` + قيد يوجب وقتًا |
| ملخّص الحقوق لا يطبع اسمًا | أعداد وحالات فقط (فحص طفريّ يمنع طباعة الأسماء) |
| مسوّدة لا تُفرَض على طاقم | `sop_attach_to_task` يشترط `approved` |
| لا ادّعاء امتثال | (G-3) يمنع ISO/certified/SLA/ضمان |
